Windows_SC {{VERSION}}
=====================

対応環境:
- Windows 11 25H2以降（OSビルド26200以降）
- x64
- 下端タスクバー
- 1080p以上を推奨（1080p未満では未検証の警告を表示して起動を続行）

起動方法:
Windows_SC.exeを実行してください。起動後は通知領域へ常駐します。

主な表示方法:
- Windowsキー単体
- スタートボタン
- Ctrl + Alt + Space
- 通知領域アイコン

設定とログ:
%LOCALAPPDATA%\Windows_SC

この配布物は自己完結版です。Visual Studioや.NET SDKを別途インストールする
必要はありません。

注意:
- Windows_SC.exeと同梱DLL等を同じフォルダーに置いたまま使用してください。
- 展開フォルダーを移動した場合は、自動起動を設定し直してください。
- 詳細ログを共有する前に、コマンドや音声デバイス名等を確認してください。
- Windowsのセキュリティ機能により、未署名アプリとして警告される場合があります。
