# Windows_SC

Windows 11のスタートメニューと一緒に表示できる、常駐型の個人向けランチャーです。
アプリ、ファイル、フォルダー、URL、コマンド、キー入力、マクロ、音声出力先、
マスター／アプリ別音量を一つの画面から操作し、CPU／GPU／メモリも確認できます。

現在のソースバージョンは`0.9.1`です。GitHubで公開済みのタグ／配布版は
`v0.6.2-beta.1`で、`0.9.1`はまだ配布物の作成、配布前確認、タグ付けを
完了していません。

## 対応環境

- Windows 11 25H2以降（OSビルド26200以降）
- x64
- 下端タスクバー
- 1080p以上を推奨。1080p未満は未検証

Windows 10、Windows 11 24H2以前、x86／ARM64、下端以外のタスクバーは
現在のサポート対象外です。起動時にOSビルド、アーキテクチャ、タスクバー位置を
検査し、対象外の場合は理由を表示して終了します。接続中のディスプレイに
1080p未満の解像度がある場合は、未検証であることを警告してから起動を続けます。
解像度は起動時の終了条件ではありません。

## 基本操作

アプリを起動すると通知領域へ常駐します。ランチャーは次の方法で表示できます。

- Windowsキー単体
- タスクバーのスタートボタン
- `Ctrl+Alt+Space`
- 通知領域アイコンの「ランチャーを表示」

通知領域アイコンから、ランチャー表示、設定、アプリ終了を選択できます。

## 登録できる項目

- ボタン
  - アプリ、ファイル、フォルダー、URLを開く
  - コマンド／batを実行する
  - ランチャーを閉じ、登録したショートカットキーをScanCode方式またはVirtualKey方式で直前のアプリへ送る
  - 操作、キー入力、待機を登録順に実行するマクロ
- 循環切り替え
  - 音声出力デバイスを登録順に切り替える
  - 複数のコマンドを登録順に実行する
  - ランチャー上には、現在値ではなく次に切り替わるデバイスまたは操作を表示する
- 音量スライダー
  - 現在の既定音声出力のマスター音量を変更する
  - 既定音声出力がミュート中は、音量値の代わりに「ミュート」とリアルタイム表示する
  - 現在の既定出力上にある対象アプリの音量を変更する
  - アプリ別音量は出力デバイスごとに保存し、既定出力を戻したときに復元する
- システムモニター
  - CPU、GPU、メモリから1つまたは2つを選択して使用率を表示する
  - 1項目選択時は、現在値に加えて最大60秒の履歴グラフを表示する

起動対象欄のフォルダーアイコンから、ファイルまたはフォルダーを選択できます。
PATHで解決できる`notepad.exe`等、URL、Windows URIは手入力も可能です。

## 設定

設定は自動保存されません。設定画面下部の「保存」を押した時点で、入力検証、
設定ファイル保存、自動起動の反映、ランチャー表示の更新を行います。

主な設定:

- スマートフォン連携パネル用の表示位置調整
- 標準／コンパクト表示
- Windowsログオン時の自動起動
- ランチャー項目の追加、編集、削除、並べ替え
- 常時有効の通常ログ
- 24時間または手動解除まで継続できる詳細診断ログ

## データ保存場所

設定とログは次へ保存します。

```text
%LOCALAPPDATA%\Windows_SC\
├─ Settings\
│  ├─ settings.json
│  └─ application-volume-state.json
└─ Logs\
```

設定画面の「データフォルダーを開く」から確認できます。アプリが設定やログを
外部へ自動送信することはありません。詳細ログにはコマンドや音声デバイス名等が
含まれる可能性があるため、共有前に内容を確認してください。

## 開発用ビルド

製品コードは、UI非依存の`Windows_SC.Core`とWinUIアプリの`Windows_SC`で構成されています。
`Windows_SC.Tests`はCore成果物を参照してテストします。

```powershell
dotnet build Windows_SC.slnx -c Debug -p:Platform=x64 --no-restore
dotnet build Windows_SC.slnx -c Release -p:Platform=x64 --no-restore
```

配布物はx64自己完結版です。利用先にVisual Studio、.NET SDK、Windows App SDKを
別途インストールする必要はありません。

現在の配布スクリプトが生成するのは、次の通常ZIP版だけです。

- `Windows_SC-<version>-x64.zip`: 展開後、フォルダー内の
  `Windows_SC.exe`を実行する。起動が安定し、問題発生時に中身を確認しやすいため
  現時点の検証済み形式として使用する。

公開配布はZIPまたは単一EXEを目的とし、MSIXは公開対象にしません。単一EXEは
過去に一部PCでWinUI初期化エラー`0x80040111`が発生したため現在は生成しておらず、
再採用する場合は問題が出たPCを含む対象環境で起動確認を行います。

自動起動を有効にした後で展開フォルダーを移動すると登録先が古くなるため、
移動後は設定から自動起動を設定し直してください。

現在、タスクバー中央揃えでスマートフォン連携パネルを表示した場合と、
1080p未満では、スタートメニューとランチャーの間隔が広くなる等の配置問題が
生じる可能性があります。現在は1080p未満の検証環境を用意できないため警告対象です。
パネルの正確な外周を安定して取得できない点と合わせ、既知の配置制約として
管理しています。

`0.9.1`の未リリースソースには、スタート検出診断に加え、ShortcutKey、マクロ、
出力先別のアプリ音量、システムモニターを実装しています。Debug／Release x64は
警告・エラー0、Core自動テスト70件は成功しています。新機能のGUI操作、2台の音声出力での
復元、長時間常駐、現在版ZIP、別PCは未確認であり、配布前に試験チェックリストを
実施する必要があります。

配布物の作成:

```powershell
.\scripts\Build-Distribution.ps1
```

成果物は`artifacts\distribution`に作成されます。詳しくは
[配布手順](docs/DISTRIBUTION.md)を参照してください。
