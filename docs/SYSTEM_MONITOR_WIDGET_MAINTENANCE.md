# システムモニター 保守ガイド

更新日: 2026-08-09

## 現行仕様

- `LauncherItemKind.Widget`の初回種類は`WidgetKind.SystemMonitor`だけである。
- 1カードへCPU、GPU、メモリを3行で表示し、メモリは使用量／総容量も表示する。
- 標準／コンパクトのどちらも2列幅を使う。

## 取得方法

- CPUは`GetSystemTimes`のIdle／Kernel／User差分から求める。初回は差分がないため`—`とする。
- メモリは`GlobalMemoryStatusEx`の物理メモリから割合と使用量を求める。
- GPUは`\\GPU Engine(*)\\Utilization Percentage`をPDHで列挙し、有効値の最大を代表値とする。
- GPUカウンターがない、RDP等で取得できない、初回値が未確定の場合は`—`とし、0%と誤表示しない。
- GPU値はタスクマネージャーと集計方法が完全には一致しない。

## 寿命とログ

- ランチャー表示時だけタイマーを即時開始し、その後1秒間隔で更新する。非表示時は停止する。
- PDH Query、タイマー、イベントはアプリ終了時に解放する。
- 毎秒の失敗を通常ログへ出さず、GPU取得可否が変わったときだけ記録する。
- 変更後は標準／コンパクト、GPU取得不能、RDP、非表示中の停止、1～2時間常駐後の
  CPU・メモリ・ハンドル増加を確認する。
