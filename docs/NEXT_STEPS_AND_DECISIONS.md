# 現在の状況と残作業

更新日: 2026-11-06。対象: mainの作業ツリー、Windows_SC **0.9.10**（MSIXメタデータ0.9.10.0）。

## 現在の実装

- Start検出はWin32が既定。Win32イベントと125ms確認を併用し、Windowsキー後は50ms・最大1500ms確認する。
- UIA監視は「次回起動時のUIA監視」を明示保存し、再起動して反映する。復帰時も起動時の選択を維持する。
- モニターは選択項目だけを毎秒採取し、非表示中も履歴を保持する。画面更新は表示中だけ行う。
- 保存を直列化し、終了時は明示保存の完了を待つ。UI・Composition・監視・音声・ロガーの解放を管理する。
- 未使用表示、一回用小関数、重複検証、未使用の保存キャンセル引数を整理済み。
- 通常診断ログは存在する。特別版のMemory Flight CSV／WPR機能はmainに含まない。
