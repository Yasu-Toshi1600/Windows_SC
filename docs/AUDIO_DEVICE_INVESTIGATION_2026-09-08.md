# 音声削除クラッシュの継続調査

更新日: 2026-11-06。未解決のため現行docsで管理する。

## 残っている問題

0.9.5で「不明な音声デバイス」行の削除時にアクセス違反が報告された。
ダンプのスタックはWinUI ListViewのポインター・選択表示更新内にあり、原因は未確定。
UI Automation Invoke一回では再現せず、物理クリックの再現試験は未成立。
現在のmainで解消したとは確認していない。

## 次の確認

- 物理クリックによる削除・連続削除・選択移動・未保存終了を実機確認する。
- 再現時は本体DLL／PDBと照合できるフルダンプを採取し、WinUI内の不正オブジェクトを調べる。
- StableId取得・ID変更後の追従、未接続表示、登録先差し替え、保存・再起動を別途確認する。
  StableId・表示名保存・差し替えは実装済みだが、削除クラッシュの解決証拠にはしない。

現行仕様は[機能保守](FEATURE_MAINTENANCE.md)、操作項目は[チェックリスト](TEST_CHECKLIST.md)。
ログ・ダンプ解析・版ごとの結果は[9月の調査履歴](archive/AUDIO_DEVICE_INVESTIGATION_2026-09-08.md)へ退避した。
